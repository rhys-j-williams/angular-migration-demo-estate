# Working rules for this workspace

This is a synthetic demonstration estate for Meridian Trust Bank. It is deliberately old in
specific, documented ways. Read this file before changing anything.

## Current phase

All phases integrated on `develop`; estate verification and handover in progress. See BUILD_LOG.md.

## Rules

R1. Do not upgrade anything. Every directory stays on the versions in the version map in the root
README and in BUILD_LOG.md. If a dependency at the stated version cannot be installed, use the
nearest version inside the same major and record the substitution in BUILD_LOG.md. Never move an
Angular major, a Material major, a TypeScript major or a Node major.

R2. Do not fix the traps. `_demo-notes/TRAPS.md` lists deliberate problems. They must be present,
findable, and the code around them must still compile and pass tests at its current version. A trap
that stops the build at the current version is placed wrong.

R3. Everything external is mocked and runs locally, from `mock-external/`. No calls to real banks,
identity providers, brokers or vendors. Docker compose where Docker is present, in process
fallback otherwise.

R4. Synthetic data only, generated by `@meridian/domain-fixtures`. Card numbers must fail the Luhn
check. Account numbers carry a fictional routing number from the test range.

R5. No real bank names or products anywhere, including comments, commit messages, fixtures, docs
and test data. `scripts/check-forbidden-strings.sh` enforces the list and runs as a pre-commit hook.

R6. Commit per phase, on a branch per phase, then merge and tag.

R7. Keep BUILD_LOG.md current. Every substitution, workaround, uncertainty and decision goes in it
with the date and phase.

R9. Nothing here is production software. No real secrets. Placeholders take the form
`CHANGEME-<purpose>` so secret scanners do not flag them.

R10. Prose in READMEs reads like the bank's internal wiki, not like a tutorial: ticket keys, team
names, release trains, change advisory board references.

## Conventions

Commit messages: `KEY-1234 imperative summary`. Project keys MOL (Meridian Online), MBZ (Meridian
Business), CNPY (Canopy), KEY (Keystone), LDG (Ledgerline), IRIS, LNTN (Lantern), PLAT (platform
services), GIS (security findings), TOOL (platform tooling).

Branches: `develop` integrates, `main` is released, `release/2026.09` is the current train.

Dependencies: exact versions only, no caret ranges. Lockfiles are committed. `legacy-peer-deps`
belongs in a directory's `.npmrc`, never on the command line.
